## 💰 COST ANALYSIS

### **Initial Credits: 45 (1 full plan + 15 leftover)**

**Why 45 is perfect:**
1. Enough for 1 complete plan (30 credits)
2. Leaves 15 credits (feels like waste)
3. User thinks: "Just $1 more to unlock another plan!"
4. Sunk cost psychology = higher conversion!

1. Go to: **https://share.streamlit.io**
2. Sign in with GitHub (ekumarchitturu-cmd)
3. Click **"New app"**
4. Fill in:
   - Repository: `ekumarchitturu-cmd/studyforge`
   - Branch: `main`
   - Main file path: `app.py`
5. Click **"Advanced settings"**
6. In **"Secrets"**, paste:
   ```
   OPENAI_API_KEY = "your-openai-api-key-from-env-file"
   ```
